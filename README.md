# منصة المستر سعد عويضة للعلوم — الإصدار 68.5.4

## جديد 68.5.4

- اشتراط الاسم الثلاثي على الأقل في كل مسارات تسجيل الطلاب.
- طلب الاسم الرباعي عند وجود طالب آخر بنفس الاسم الثلاثي.
- منع تسجيل نفس الطالب أكثر من مرة بالاسم من الحجز العام أو لوحة الإدارة أو الاستيراد.
- تطبيع الأسماء العربية قبل المقارنة مع قفل مركزي ذري يمنع التكرار المتزامن من أجهزة مختلفة.
- تحرير الاسم المحجوز تلقائيًا عند رفض الحجز أو حذف الطالب بأمان.
- رسالة واضحة للطالب والإدارة عند محاولة تسجيل اسم موجود بدل إنشاء أكواد وحسابات مكررة.

- تدقيق أمني لكل روابط الملفات والمحتوى الخارجية وقصرها على HTTPS/HTTP.
- إضافة حماية `noopener noreferrer` لكل الروابط التي تفتح في نافذة جديدة.
- منع فهرسة صفحة التحويل القديمة للأسئلة وتوجيه Canonical إلى بنك الأسئلة.

- إزالة بطاقات الزينة المتداخلة فوق صورة المستر وتثبيت أبعاد الصورة أثناء التحميل.
- إضافة اختبار يمنع عودة مساحة «متابعة مستمرة» البيضاء أو تغطية صورة المستر.
- منع Firebase من منافسة صورة المستر والتنسيق أثناء أول تحميل للصفحة الرئيسية.
- إلغاء تبديل CSS المتأخر الذي كان يعيد تخطيط الواجهة ويرفع زمن LCP.
- دعم روابط YouTube داخل الكورسات والدروس وفتح الفيديو مباشرة خارج المنصة.
- تشغيل Firebase عند التفاعل أو الاقتراب من قسم ديناميكي فقط، دون تشغيل تلقائي أثناء اختبار الصفحة الأولى.
- إصلاح اتصال Firebase Auth مع `apis.google.com` داخل سياسة CSP.
- تحسين preload المتجاوب لصورة المستر ومنع تحميل مقاس غير مستخدم.

- تحسين مسار العرض الأول على الموبايل باستخدام Critical CSS وتحميل التنسيق الكامل دون حجب أول رسم.
- إضافة صورة موبايل محسنة لصورة المستر مع `srcset` وتهيئة تحميل LCP.
- تفعيل كاش طويل للملفات ذات رقم الإصدار وتقليل حمولة تثبيت الـPWA.
- استكمال بيانات الفهرسة وCanonical وOpen Graph وSchema.org وخريطة الموقع.
- تصحيح عدد الصفوف الظاهر في الصفحة الرئيسية إلى 9 صفوف.

- الحجز يدعم الدفع في السنتر أو فودافون كاش أو إنستا باي.
- رفع إيصال صورة/PDF للتحويل الإلكتروني ومراجعته من طلبات التسجيل.
- لا يمكن قبول التحويل الإلكتروني قبل اعتماد الإيصال، ويُسجل الدفع تلقائيًا بعد الاعتماد.
- الموعد اختياري؛ يمكن للطالب الحجز وتحديد المجموعة لاحقًا.
- تقرير ولي الأمر يُنشأ PDF عربيًا مفصلًا وقابلًا للمشاركة إلى واتساب من الموبايل.
- التقرير يوضح الحضور والدرجات والواجب والتسميع والدفع وترتيب الطالب وهل هو من الأوائل.
- الامتحانات تستمر في الاستهداف حسب نوع الدراسة والصف والمجموعة، مع PDF أو أسئلة أو الاثنين.
- الهيدر العام يعرض زر اتصال واحدًا بدل تكرار الاتصال والحجز.

## التشغيل المحلي

على Windows شغّل `start-site.bat`، أو نفّذ:

```powershell
npm install
npm run dev
```

ثم افتح:

```text
http://127.0.0.1:5173
```

صفحة الإدارة:

```text
http://127.0.0.1:5173/teacher-login.html
```

الخادم المحلي يبني `dist/` أولًا ويوقف كاش المتصفح حتى ترى آخر تعديل مباشرة.

## الاختبار والبناء

```powershell
npm test
npm run build
```

نسخة النشر النهائية تُنشأ داخل `dist/`.

## النشر الكامل على Firebase

لنشر قواعد Firestore وStorage فقط بدون نشر الموقع أو الـFunctions، شغّل على Windows:

```text
deploy-firebase-rules.bat
```

سيفتح تسجيل Google الرسمي ثم ينشر `firestore.rules` و`firestore.indexes.json` و`storage.rules` فقط، ولا يحذف بيانات الطلاب.

خصائص كود طالب الأونلاين، الدفع، الواجبات، الامتحانات وباركود الحضور تحتاج نشر الواجهة والدوال والقواعد معًا:

```powershell
npm run firebase:deploy:all
```

أو على مرحلتين:

```powershell
npm run firebase:deploy:backend
npm run firebase:hosting
```

نشر `dist/` فقط يحدّث الشكل، لكنه لا يحدّث منطق Cloud Functions أو قواعد Firebase.

## النشر على Vercel

- Framework: Other
- Build Command: `npm run build`
- Output Directory: `dist`

عند استخدام Vercel للواجهة، انشر Firebase backend أولًا:

```powershell
npm run firebase:deploy:backend
```

## إعداد اختياري للحماية

ضع مفتاح reCAPTCHA الخاص بـ Firebase App Check في `assets/firebase-config.js` داخل `appCheckSiteKey` بعد تسجيل الدومين في Firebase Console. اتركه فارغًا أثناء التجربة المحلية.
